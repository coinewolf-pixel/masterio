# Masterio CRM — веб-админка (`apps/admin`)

React 19 + Vite, TanStack Query, react-router, i18next (en, ru), Leaflet, Socket.IO.

> Нужен общий пакет из `masterio-shared-phase-7.zip`, распакованный в `packages/shared` (см. корневой README).
> Vite берёт `@masterio/shared` прямо из исходников — собирать пакет для админки не нужно.

## Разделы и права

| Раздел | Что делает | Кто видит |
|---|---|---|
| Сводка | заказы за сегодня, что происходит сейчас, пульс городов и «мало мастеров», очереди | все |
| Живая карта | мастера онлайн и на заказах (движутся в реальном времени), заказы без мастера | все |
| Заказы | фильтры в адресе страницы; карточка: маршрут, хронология, журнал рассылки, сметы, чат, фото, деньги, проводки, отмена поддержкой | все; отмена — support |
| Документы | очередь KYC, лицензий, страховок, документов участников команд (видно команду и роль); файл по временной ссылке, каждый просмотр — в журнал | support, moderator |
| Мастера / Клиенты | поиск по телефону или ID, карточка, допуск к заказам, кошелёк по карманам, блокировка с причиной; у мастера — команда (участники, приглашения, журнал) или в чьей команде он состоит | все; кошелёк — finance; блокировка — moderator |
| Стартовый баланс | быстрые суммы 50 / 100, своя сумма, причина, срок; очередь второго подтверждения | finance (создать), superadmin (подтвердить) |
| Финансы | обороты, комиссия и откуда списана, кредиты, бонусы, остатки, сверка журнала, операции, CSV | finance |
| Подозрительное | отметки (отмены, GPS, оплата мимо приложения…) и итог проверки | moderator |
| Настройки | все параметры без релиза, по уровням: везде / страна / город / услуга / город+услуга, история | finance (финансовые ключи), superadmin |
| Услуги и города | названия на 5 языках, флаги «срочно», «лицензия», «страховка», услуги каждого города | superadmin меняет, остальные видят |
| Споры, Обращения, Инциденты | очередь, материалы, действия поддержки, итог; возврат комиссии — finance | support, moderator, finance |
| Юридические документы, Страхование | редакции на 5 языках с проверкой юриста; правила страхования по стране, услуге, типу мастера | superadmin меняет |
| Бонусы, Персональные данные | правила и месячные расчёты с одобрением; выгрузки и удаления (GDPR) | finance; support |
| Админы, Журнал действий | роли, лимиты, сброс TOTP с QR; кто, что, когда, до и после | superadmin |

Права проверяет сервер; CRM только прячет недоступные разделы и кнопки.

## Переменные

Скопируйте `.env.example` в `.env`. Переменные `VITE_*` попадают в собранные файлы — секретов там нет.

| Переменная | Что это |
|---|---|
| `VITE_API_URL` | `https://<домен API>/api/v1` |
| `VITE_MAP_TILE_URL`, `VITE_MAP_ATTRIBUTION` | подложка карты. Публичные тайлы OpenStreetMap — только для разработки; в продакшене — сервис с ключом, ограниченным доменом админки (MapTiler, Stadia Maps) |

На сервере добавьте адрес админки в `CORS_ORIGINS` (через запятую), иначе браузер не пустит запросы и сокет.

## Первый вход

1. На сервере задайте `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD` (12+ символов) и выполните `pnpm --filter @masterio/api seed`.
2. В логе будет ссылка `otpauth://…` — добавьте её в Google Authenticator / 1Password (или вставьте секрет вручную).
3. Войдите: email, пароль, 6-значный код. Остальных админов создавайте в разделе «Админы» — QR показывается один раз.

## Запуск в разработке

```bash
pnpm install
cd apps/admin
pnpm dev            # http://localhost:5173 (этот адрес уже в CORS_ORIGINS из .env.example сервера)
```

## Деплой на Railway

1. New Service → GitHub repo, Root Directory — корень репозитория (пустой).
2. Settings → Config-as-code → путь `/apps/admin/railway.json`. В нём сборка (сначала общий пакет `@masterio/shared`, затем CRM), запуск статического сервера с SPA-маршрутами, CSP и запретом iframe, проверка `/` и пересборка только при изменениях CRM или общего пакета.
3. Variables: `VITE_API_URL`, `VITE_MAP_TILE_URL`, `VITE_MAP_ATTRIBUTION` — нужны на этапе сборки.
4. Settings → Networking → Generate Domain (или свой домен) и этот адрес — в `CORS_ORIGINS` сервиса API.

Подойдёт и любой статический хостинг (Cloudflare Pages, Netlify): выложите `dist/`, все пути отдавайте на `index.html`.
Политика безопасности разрешает запросы только по `https:`/`wss:` — API в продакшене должен быть на HTTPS (на Railway так по умолчанию).
