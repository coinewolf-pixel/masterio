# Чек-лист ручной проверки — фазы 2–7

Проверяется через Swagger (`/docs`) или Postman. Код SMS в разработке — в логе сервера (`SMS_PROVIDER=console`).

**Вход и безопасность**
- [ ] Запрос кода → код в логе → вход клиента; повторный вход тем же номером возвращает того же пользователя.
- [ ] 5 неверных кодов подряд → «Слишком много неверных кодов», верный код тоже не принимается 15 минут.
- [ ] Шестой запрос SMS на один номер за час → 429.
- [ ] Обновление токена выдаёт новую пару; старый refresh-токен повторно → сессия завершена.
- [ ] Вход в CRM: пароль + код из приложения-аутентификатора; неверный код TOTP → 401.

**Каталог**
- [ ] `/categories` возвращает 5 групп и 20 категорий; названия на en, ru, de, es, hy.
- [ ] `/cities` возвращает Ереван (AMD), Берлин, Мадрид, Вену (EUR).

**Мастер**
- [ ] Новый мастер: `/worker/eligibility` показывает причины (KYC, категории, город, баланс, офлайн).
- [ ] Админ подтверждает KYC, начисляет 100 (кнопка-пресет) → причина «баланс» исчезает, кошелёк показывает «Приветственный кредит» со сроком.
- [ ] Вывода с кошелька нет: любые пути вида `/wallet/withdraw` → 404.

**Рассылка (поставьте `OFFER_TTL_SECONDS` = 10 для удобства)**
- [ ] Три мастера онлайн рядом → заказ получает только ближайший, остальные ничего не видят.
- [ ] Не отвечать 10 секунд → предложение исчезает, получает следующий.
- [ ] Отказ → следующий; во втором круге отказавшемуся заказ не приходит.
- [ ] `BATCH_SIZE` = 2, два мастера одновременно нажимают «Принять» → один получает заказ, второй — «Заказ уже занят».
- [ ] Перезапуск сервера во время открытого предложения → после запуска рассылка продолжается.
- [ ] Никого рядом → клиент получает «Мастеров сейчас нет»; «Расширить радиус» запускает поиск заново.

**Заказ и наличные**
- [ ] «Прибыл» в 400 м от адреса → «нужно находиться по адресу»; в 50 м → успешно.
- [ ] Клиент в комнате заказа видит позицию мастера, расстояние и ETA; при приближении на 500 м — push «Мастер рядом».
- [ ] «Завершил» без подтверждённой сметы → отказ; смета 100 → клиент подтверждает → «Завершил, получил 100» → комиссия 20 списана с приветственного кредита.
- [ ] Клиент подтверждает 100 → заказ подтверждён; подтверждает 80 → автоматически открыт спор.
- [ ] Отзыв только после подтверждения и только один раз.
- [ ] После завершения клиент больше не может войти в комнату трека.

**Отмены**
- [ ] Отмена до принятия — бесплатно; через 10 минут после принятия — штраф; когда мастер «Прибыл» — компенсация за выезд.
- [ ] Причина «мастер просит оплату вне приложения» → без штрафа, создаётся отметка для проверки.
- [ ] Мастер отменяет после принятия → заказ снова в поиске, ему больше не приходит.

**Деньги и настройки**
- [ ] Начисление выше порога ждёт второго админа; создатель подтвердить не может.
- [ ] Пополнение: тестовый платёж Stripe → webhook → баланс «Пополнение» вырос (сначала гасится долг); повтор webhook не дублирует.
- [ ] Комиссия 25% в настройках → отклоняется; 15% → действует сразу без перезапуска.
- [ ] `CASH_ENABLED` = false → новый наличный заказ отклоняется сразу; можно выключить только для одного города.
- [ ] `/admin/finance/ledger-integrity` → сумма 0, расхождений 0.

**Документы (сервер)**
- [ ] Мастер загружает удостоверение и селфи → в `/admin/documents` очередь из двух; модератор подтверждает оба → KYC пройден.
- [ ] Отклонение без причины не принимается; с причиной — мастер видит причину и получает push.
- [ ] Чужой файл или незагруженный файл зарегистрировать нельзя; файл больше 10 МБ не принимается.
- [ ] Категория «Электрик» требует лицензию: без неё заказ не приходит, после подтверждения — приходит, у клиента значок «Лицензия подтверждена».

# Masterio Pro на телефоне (фаза 3)

Нужна dev- или preview-сборка (см. `apps/worker/README.md`), сервер с `PUSH_PROVIDER=expo`.

**Вход и язык**
- [ ] Язык приложения совпадает с языком телефона; переключение на каждом из 5 языков (en, ru, de, es, hy) меняет все экраны сразу и сохраняется после перезапуска.
- [ ] Вход по SMS: код вставляется автоматически (iOS/Android), неверный код — понятная ошибка, «Отправить ещё раз» через 60 секунд.
- [ ] Анкета: без имени, услуги или города кнопка неактивна; «Компания» требует название.

**Документы**
- [ ] Удостоверение и селфи с камеры (селфи — фронтальная камера), статус «На проверке» → «Подтверждён» после решения модератора.
- [ ] Лицензия для услуги, которая её требует; отказ в доступе к камере → понятное сообщение.

**Работа и заказы**
- [ ] Первое «На линии» запрашивает геопозицию «При использовании», затем «Всегда»; отказ → баннер с кнопкой «Открыть настройки».
- [ ] При нехватке баланса — причина и кнопка «Пополнить»; после пополнения причина исчезает.
- [ ] Заказ от клиента: карточка поверх любого экрана со звуком и вибрацией, отсчёт 30 секунд. При неправильном времени на телефоне отсчёт всё равно верный.
- [ ] Не отвечать 30 секунд → карточка закрывается. Клиент отменил → «Заказ уже недоступен».
- [ ] Приложение свёрнуто или экран заблокирован → push с предложением; нажатие открывает карточку.
- [ ] Принять → экран заказа; «Маршрут» открывает Google Maps; чат: номер телефона в сообщении скрывается.
- [ ] «Прибыл» далеко от адреса → «нужно находиться по адресу»; на месте — успешно.
- [ ] Свернуть приложение во время заказа: на Android видно уведомление «Masterio Pro: активный заказ», клиент продолжает видеть движение.
- [ ] Включить режим полёта на минуту во время заказа → клиент видит «связь потеряна»; после включения сети точки досылаются, трек без разрыва.
- [ ] Смета → клиент подтверждает → «Завершил, получил наличными» → разбивка: комиссия, скидка бонуса, списано; кошелёк уменьшился.

**Кошелёк и история**
- [ ] Пополнение тестовой картой Stripe 4242 4242 4242 4242 → через минуту баланс «Пополнение» вырос.
- [ ] Карманы отображаются отдельными строками, приветственный кредит — с датой окончания, вывода нет.
- [ ] История: сводка за месяц сходится со списком заказов, переключение месяцев, экспорт CSV открывается в «Поделиться».

# Masterio на телефоне (фаза 4)

Нужны dev- или preview-сборки Masterio и Masterio Pro на двух телефонах, сервер с `PUSH_PROVIDER=expo` и ключом `GOOGLE_MAPS_API_KEY` (Places API (New), Geocoding API), в Masterio — ключи Maps SDK.

**Вход и главная**
- [ ] Язык как на телефоне; переключение на каждый из 5 языков в профиле меняет все экраны и сохраняется после перезапуска.
- [ ] Вход по SMS, имя при первом входе; на главной срочные услуги первыми.

**Новый заказ и адрес**
- [ ] «Моё местоположение» спрашивает разрешение «При использовании» (фоновое не запрашивается), подставляет адрес; отказ → понятное сообщение, поиск адреса работает.
- [ ] Поиск: подсказки появляются после 2 букв, выбор ставит метку на карту; перетаскивание карты меняет адрес.
- [ ] Подъезд/этаж, «Сохранить адрес» с названием → адрес появляется в «Мои адреса», удаление работает.
- [ ] Фото с камеры и из галереи прикрепляются, долгое нажатие удаляет; без описания или адреса кнопка неактивна.
- [ ] Под адресом видно, сколько свободных мастеров рядом и расстояние до ближайшего.

**Поиск и живая карта**
- [ ] После заказа — «Ищем мастера»; на телефоне мастера приходит предложение. Никто не принял → варианты «искать в радиусе N км», «искать снова», отмена бесплатно.
- [ ] Мастер принял → push «Заказ принят», карточка мастера с рейтингом и значками, кнопки «Позвонить» и «Чат».
- [ ] Мастер нажал «Выехал» → на карте его машина, она плавно движется (без скачков) и поворачивается по направлению, видны путь, пунктир до адреса, расстояние и время прибытия.
- [ ] Сдвинуть карту → появляется кнопка «вернуть», карта перестаёт следовать; нажатие возвращает мастера и адрес в кадр.
- [ ] Мастер включил режим полёта → через минуту «Связь с мастером потеряна», метка бледнеет; после включения сети движение продолжается.
- [ ] Свернуть Masterio и снова открыть → карта сразу показывает мастера (без ожидания следующей точки).
- [ ] «Мастер на месте» → push и баннер на экране заказа.

**Смета, оплата, отзыв**
- [ ] Новая смета → push, строки и итог; «Утвердить» / «Отклонить»; изменённая смета показывает прежнюю сумму.
- [ ] Мастер завершил → сумма мастера подставлена; та же сумма → «Подтверждён»; другая сумма → предупреждение и спор.
- [ ] Отзыв со звёздами — один раз; после отправки — «Спасибо за отзыв».
- [ ] «Не предлагать мои заказы этому мастеру» → новый заказ этому мастеру не приходит; «Снова предлагать» отменяет.

**Отмена и история**
- [ ] Отмена до выезда — «бесплатно»; после выезда мастера — показана плата за отмену до подтверждения.
- [ ] «Мастер просит оплату вне приложения» — отмена без платы, сообщение о проверке.
- [ ] «Мои заказы»: сводка за месяц совпадает со списком; «Повторить заказ» открывает форму с той же услугой и описанием.

# Masterio CRM (фаза 5)

Нужны развёрнутые API и CRM, первый суперадмин из seed, аутентификатор на телефоне, один телефон с Masterio Pro и один с Masterio.

**Вход и права**
- [ ] Вход: неверный пароль или код → понятная ошибка; после 15 минут работы сессия продлевается сама; закрыть вкладку → нужен новый вход.
- [ ] Создать админов support, moderator, finance: у каждого видны только свои разделы; прямой адрес чужого раздела → «нет доступа»; запрос из консоли браузера к чужому API → 403.
- [ ] Сменить роль админу → его сессия закрывается сразу. Отключить последнего суперадмина нельзя.
- [ ] Сбросить код аутентификатора → QR показывается один раз, старый код не работает.
- [ ] Переключить язык en/ru: все экраны и сообщения об ошибках на выбранном языке.

**Работа**
- [ ] Сводка: создать заказ в Masterio → «Ищут мастера» увеличивается; в городе меньше `LOW_WORKERS_WARNING` мастеров → предупреждение.
- [ ] Живая карта: мастер выходит на линию → зелёная метка; принимает заказ и едет → метка двигается без обновления страницы; уходит с линии → метка исчезает.
- [ ] Заказы: фильтр по статусу, городу, услуге, дню, номеру; ссылку с фильтрами открыть в другой вкладке — те же результаты.
- [ ] Карточка заказа: маршрут на карте, хронология, журнал рассылки (кому, когда, итог), смета, чат с замаскированным телефоном, проводки комиссии.
- [ ] Отмена заказа поддержкой с причиной → клиент и мастер получают уведомление, штрафа нет, запись в журнале действий.

**Люди**
- [ ] Документы: мастер загружает удостоверение и селфи → появляются в очереди; «Открыть файл» показывает фото; одобрить оба → у мастера «личность подтверждена»; отклонить с причиной → мастер видит причину.
- [ ] Мастер: поиск по последним цифрам телефона; карточка показывает, почему он не получает заказы (баланс, KYC, офлайн…).
- [ ] Блокировка мастера → его приложение выходит из аккаунта, приветственный кредит сгорает; снятие ограничений возвращает доступ.
- [ ] Клиент: история, отмены со штрафом, чёрный список мастеров.

**Деньги**
- [ ] Стартовый баланс: finance начисляет 50 → у мастера сразу +50 в «Приветственный»; сумма выше порога → «ждёт подтверждения», создатель не может подтвердить сам, другой суперадмин подтверждает.
- [ ] Превышение лимита на мастера или дневного лимита → понятная ошибка.
- [ ] Финансы: после подтверждённого заказа 100 → комиссия 20 и источник списания совпадают с кошельком мастера; «Журнал сходится»; CSV открывается в Excel/Numbers.
- [ ] У support нет раздела «Финансы» и кошелька мастера.

**Контроль**
- [ ] Настройки: комиссия 15% для одного города → новый заказ в этом городе берёт 15%, в другом 20%; 25% сохранить нельзя; история показывает кто, когда, было/стало, комментарий; «Снять переопределение» возвращает 20%.
- [ ] Флаг `CASH_ENABLED` выключить для города → при следующем открытии формы заказа в Masterio наличных нет (без обновления приложения).
- [ ] Услуги и города: добавить город с названиями на 5 языках и включить в нём услуги → город и услуги видны в приложениях.
- [ ] Подозрительное: клиент отменил с причиной «мастер просит оплату вне приложения» → отметка появляется; «Отметить проверенным» с комментарием.
- [ ] Журнал действий: все действия выше записаны с админом, временем и «до/после».

# Споры, происшествия, документы и приватность (фаза 6)

Нужны: API, CRM, один телефон с Masterio, один с Masterio Pro, опубликованные документы для страны теста.

**Юридические документы и согласия**
- [ ] CRM → «Документы»: черновик условий для клиентов без одного из языков или без имени юриста не сохраняется; со всеми языками → «Опубликовать»; изменить опубликованную редакцию нельзя.
- [ ] Новый клиент и новый мастер после входа видят экран «Ознакомьтесь с условиями»; без согласия заказ создать и выйти на линию нельзя; «Отказаться» выходит из аккаунта.
- [ ] Опубликовать новую редакцию → при следующем открытии приложения её нужно принять снова; в CRM растёт число согласий.
- [ ] Masterio Pro → «Пополнить»: без принятых условий пополнения кнопка оплаты недоступна, есть кнопка «Прочитать и принять».

**Споры**
- [ ] Клиент открывает спор по завершённому заказу с фото → мастер получает пуш, видит причину и срок ответа; заказ в статусе «Спор».
- [ ] Мастер отвечает с фото → клиент видит объяснение; внутренняя заметка поддержки не видна ни одной стороне.
- [ ] CRM: в карточке спора есть снимок чата, сметы, хронологии и GPS-трека на момент открытия; фото открываются.
- [ ] «Решить» в пользу мастера с возвратом комиссии (делает finance) → у мастера возвращается комиссия, в финансах проводка REVERSAL; возврат больше удержанного → ошибка.
- [ ] «Не урегулировано» → стороны видят, куда обратиться дальше; спор закрыт для новых сообщений.
- [ ] Наличные: клиент вводит сумму не как мастер → спор открывается автоматически, второй не создаётся.
- [ ] Ответ не пришёл за `DISPUTE_RESPONSE_HOURS` → спор переходит на рассмотрение поддержки.

**«Клиент не вышел» и происшествия**
- [ ] Мастер на адресе раньше `NO_SHOW_WAIT_MINUTES` → «подождите ещё N мин»; вдали от адреса → ошибка; после ожидания с фото → спор «Клиент не вышел».
- [ ] «Сообщить о происшествии» → сначала экстренный номер города (звонок открывается), затем форма; в CRM происшествие с точкой на карте и обращение в поддержке.

**Поддержка**
- [ ] Новое обращение из профиля → в CRM очередь «Обращения»; ответ поддержки → пуш и статус «Поддержка ответила»; ответ пользователя снова открывает обращение.

**Страховка и сроки документов**
- [ ] CRM → «Страховка»: правило «нужна страховка, риск liability» для страны и услуги → мастер без полиса перестаёт получать заказы этой услуги, в Pro → «Документы» видит, что нужно.
- [ ] Мастер загружает полис (страховая, номер, даты, риски) → модератор подтверждает → заказы снова приходят.
- [ ] Полис истекает через 30, 14 и 3 дня → по одному напоминанию; после даты окончания документ «Истёк», заказы по услуге останавливаются.

**Бонусы**
- [ ] CRM → «Бонусы»: правило ступеней; расчёт за прошлый месяц → черновик с формулой по каждому мастеру; заказы в открытом споре и подозрительные пары не учитываются; итог не выше бюджета.
- [ ] Одобрить → мастер получает пуш, бонус в кармане «Бонус», в «Истории» строка за месяц со сроком; повторно одобрить или пересчитать нельзя.

**Мои данные**
- [ ] «Скачать мои данные» → JSON открывается по ссылке, в CRM видна выгрузка.
- [ ] Удалить аккаунт с активным заказом или долгом → понятный отказ; без них → выход, телефон и имя удалены, в CRM пользователь «удалён», спорные материалы и проводки сохранены.

# Команды и помощники (фаза 7)

Нужны: три телефона с Masterio Pro (руководитель, участник, ещё один мастер) и один с Masterio.

**Команда и приглашения**
- [ ] Руководитель: Профиль → «Моя команда» → создать команду. Для приглашения без принятых «Условий для команд» кнопка недоступна; после принятия — приглашение по номеру с ролью «Помощник».
- [ ] Новый телефон входит с этим номером → сразу видит приглашение (до анкеты) → «Принять» → анкета только с именем → документы. В приложении нет вкладок «Кошелёк» и «История», нет переключателя линии.
- [ ] Пригласить номер клиента или участника другой команды → понятная ошибка. Приглашение старше `TEAM_INVITE_TTL_HOURS` пропадает.
- [ ] Модератор подтверждает документы участника → в CRM в очереди документов видна команда участника; у руководителя статус участника «Подтверждён», ёмкость команды стала 2.

**Назначение**
- [ ] Клиент создаёт заказ → предложение приходит руководителю → «Принять» → push «Выберите исполнителя» и карточка с таймером.
- [ ] Список кандидатов: непроверенный участник показан с причиной и не выбирается. Выбрать проверенного → клиент получает push «Кто приедет» и видит имя и роль «Помощник», без документов и телефона участника.
- [ ] «Выехал» / «Прибыл» / «Начал работу» / смета / «Получил наличными» доступны только на телефоне участника; у руководителя этих кнопок нет. Клиент видит на карте движение телефона участника.
- [ ] Не выбрать исполнителя `TEAM_ASSIGN_TIMEOUT_MIN` минут → исполнителем становится руководитель, клиенту приходит уведомление.
- [ ] Пока участник на заказе, руководитель принимает второй заказ (ёмкость 2); третий заказ ему уже не предлагается.

**Замена и «пришёл не тот»**
- [ ] После выезда руководитель меняет исполнителя → у клиента экран «Приедет другой человек» → «Согласен» → у клиента новый исполнитель, у прежнего участника заказ пропал, push обоим.
- [ ] Повторить и нажать «Оставить прежнего» → исполнитель не меняется, руководитель получает push.
- [ ] Клиент: «Пришёл другой человек» → подтверждение → заказ остановлен, открыт спор «Пришёл другой человек», в CRM в карточке заказа видны исполнители и ожидаемый человек в материалах спора.
- [ ] Участник на месте сообщает о происшествии → руководитель сразу получает push.

**Состав и данные**
- [ ] Исключить участника, пока он на заказе → отказ; после завершения → исключён, приложение участника снова в обычном режиме мастера.
- [ ] Журнал команды в приложении и в CRM показывает приглашения, вступления, назначения и замены по заказам.
- [ ] Выгрузка данных участника содержит участие в команде и назначения.
- [ ] `TEAMS_ENABLED = false` для страны → создать команду нельзя, экран объясняет почему.
