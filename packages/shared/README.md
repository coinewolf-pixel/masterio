# @masterio/shared (`packages/shared`)

Общий код сервера и приложений: имена бренда, деньги в центах, бонусы, правила отмен, реестр настроек, zod-схемы запросов,
коды ошибок, события Socket.IO, фильтр чата и переводы на 5 языков (`src/locales/{en,ru,de,es,hy}.json`).

Распакуйте этот архив в `packages/shared` рядом с `apps/*` (см. корневой README).

```bash
pnpm build        # dist/ для сервера (Node.js)
pnpm test         # деньги, комиссия, бонусы, штрафы, фильтр чата, переводы
pnpm i18n:check   # CI падает, если в каком-то языке нет ключа или параметра {{...}}
pnpm typecheck && pnpm lint
```

Мобильные приложения (Expo) подключают исходники напрямую через поле `react-native` в `package.json`.

Главные модули:

| Файл | Что внутри |
|---|---|
| `brand.ts` | единственное место с именами Masterio / Masterio Pro / Masterio CRM и bundle id |
| `money.ts` | целочисленные расчёты, комиссия не больше 20%, порядок списания комиссии |
| `bonus.ts` | ступени месячного бонуса и бюджетный лимит |
| `rules.ts` | стоимость отмены, переходы статусов, расстояние, частота отправки геопозиции |
| `settings.ts` | все настройки, которые админ меняет без релиза, с проверкой значений |
| `schemas.ts` | zod-схемы всех запросов API |
| `events.ts` | события Socket.IO и их данные |
| `i18n.ts` | перевод по ключу с параметрами, выбор языка по телефону |
